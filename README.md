Рассчитывает всё, что нужно для подачи отчета о движении средств
## Запуск
1. Получаем отчет в формате .csv, называем его input.csv и кладем в корень программы
2. Запускаем
```
go run ./... input.csv
```
3. Результат в терминале:
```md
EUR
| 3.25 | 541.94 | 545.18 | 0.01 |

USD
| 8.42 | 24.03 | 16.23 | 16.22 |

Акции
| 74.25 | 158.67 | 3.39 | 229.53 |
```

## Как получить .csv файл
1. Вкладка "Performance and Reports"
2. "Выписки"
    1. Если не создан, то создаем "Пользовательские отчеты"  +
    2. Название "Money movement", Тип отчета - "Выписка по операциям"
    3. Выделяем:
        1. "Отчет о денежных средствах"
        2. "Чистая стоимость активов (NAV)"
        3. "Отчет о движении денежных средств"
    4. Внизу ничего не меняем, только:
        1. PDF, Месячный, русский
    5. Далее/Создать
3. У меня уже создан пользовательский отчет: "Money movement" - Запустить
4. Период "Индивидуальный срок"
5. Даты - с 1го Января по 31 Декабря (Может такое быть, что не дает, если выходной)
6. Качаем сперва PDF, потом открываем еще раз и качаем CSV
    - PDF нужен для прикрепления на сайте
    - CSV - для расчета в программе
